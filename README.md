# SVG YSWS

Grind SVG. Build Games. Get a Handheld.

A small retro-gaming site and beginner guide for building playable games with SVG and JavaScript.

## Files

- `index.svg`: the home page. Home, Mission (three tabs), Learn, Rewards and Join.
- `games.svg`: the Games page. Playable Pong, plus links to Pixel Dodge and ideas for more games.
- `SVG-GAME-GUIDE.svg`: the beginner guide, in six tabs, one per part.
- `examples/pixel-dodge.svg`: a finished, playable example game.
- `guide-assets/`: small diagrams used by the guide.
- `logo.png`, `favicon.png`: the logo and icon.
- `old/`: previous versions, kept as backup. Safe to delete.

## How to open and test

1. Keep the whole folder together. The pages link to each other with relative paths.
2. Double-click `index.svg` to open the site in your browser.
3. Click the top navigation buttons. Games opens `games.svg`.
4. On the Games page, move the mouse over the green Pong box to play.
5. Open `SVG-GAME-GUIDE.svg` and switch between the six tabs.

Works in Chrome, Firefox and Edge.

## Notes

- Each page is one SVG file with embedded CSS and JavaScript. There are no external libraries.
- Placeholder links (the submission form and the official rules) are not real yet.
- On phones the pages scale down to fit, so text is small. A separate mobile layout would be a next step.
- Reward quantities, shipping and eligibility are not defined here. Check the official program rules.
- The files are checked for XML errors only. Test the games and links in a browser yourself.
